TL;DR

3DGS segmentation renders accurate masks but selects an incomplete set of object Gaussians. VODA is a plug-and-play objective whose depth-aware rasterizer supervises every Gaussian in an object's depth cluster directly, and Removal-3D measures whether removing them actually changes the scene in 3D.
